Int UI Kit 原型

按 JetBrains Int UI Kit / Int UI Icons（Figma Community）还原的界面原型。 所有尺寸与颜色来自 Figma REST API 导出的完整文档树，以及渲染图的像素采样 —— 没有一处是按名字猜的。

01主窗口
1536×960 完整 IDE：主工具栏 40 / 活动栏 41 / 项目树 360 / 编辑器 1094 / 终端 268 / 状态栏 29
02设置
891×653 = 头部 33 + 内容 563 + 底部 57，内容再分左树 283 与右区 608
03欢迎屏
欢迎页左侧动作区与右侧卡片、最近项目
04Search Everywhere
650×382 弹窗：搜索输入、All/Classes/Files/Symbols/Actions 分组、结果行
05Find in Files
677×624 弹窗：文件列表 + 命中结果，含高亮
06组件画廊
按钮 / 勾选 / 单选 / 开关 / 输入 / 标签页 / 进度 / 通知 / 表格 等分组
主题　

三套主题的标题栏颜色是实测值，与名字给人的直觉相反： Light 是浅色内容配深色标题栏 #27282E； Light with Light Header 才是全浅色 #F7F8FA； Dark 为 #2B2D30。

另有 ?bare=1：隐藏原型自身的页眉与切换条，画布按 1:1 输出，可直接用于截图或与设计稿逐像素比对。 例如 01-main-window.html?bare=1&theme=dark。

字体随包提供：Inter 与 JetBrains Mono（均可变字体，SIL Open Font License 1.1， 许可证原文见 assets/fonts/）。设计稿用的就是这两款，不打包的话会退回 Segoe UI / Consolas，字形宽度完全不同。
