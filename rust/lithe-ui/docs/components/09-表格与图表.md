# 09 · 表格与图表（`tables` / `charts`）

`tables` 从"一行数据的简单表格"到"可筛选排序分页的表格"再到"电子表格"逐级递进；`charts` 是纯自绘的图表集合，全部只读，交互只做悬停与图例开关。

> 画廊对应 `examples/gallery/pages/tables/`、`examples/gallery/pages/charts/`。

## 二、`tables` 用法

### 2.1 最简表格：`Table`

```rust
Table::new(["名称", "大小", "修改时间"])
    .row([div().child("main.rs"), div().child("1.2 KB"), div().child("今天")])
    .row([div().child("lib.rs"), div().child("3.4 KB"), div().child("昨天")]);
```

`Table::new(headers)`（`simple.rs:19`）的 `.row(cells)`（`:26`）吃 `impl IntoIterator<Item = impl IntoElement>`，所以单元格里可以放任意元素（图标、按钮、徽标）。

```rust
HeatmapTable::new(["周一", "周二", "周三"])
    .row([1.0, 4.0, 9.0])
    .decimals(1);
```

### 2.2 主力表格：`DataTable`

`DataTable` 的构造在 `options.rs`（为 `DataTable` 写的 `impl`），渲染在 `table.rs`。

```rust
let columns = vec![
    Column::new("name", "文件").width(rems(18.)).pinned(),
    Column::new("size", "大小").end().decimals(1).suffix(" KB")
        .aggregate(Aggregate::Sum),
    Column::new("state", "状态").scale(),          // 数值画成比例条
    Column::new("owner", "负责人"),
];

let rows: Rc<Vec<Row>> = Rc::new(files.iter().map(|file| {
    Row::new(file.path.clone(), [
        Cell::Text(file.name.clone()),
        Cell::Number(file.kb),
        Cell::Tag("已修改".into(), Tone::Warning),
        Cell::Person(file.owner.clone()),
    ])
}).collect());

DataTable::new("files", columns)
    .rows(rows)
    .query(query_text)
    .filters(filter_rules, false)        // 第二参数 any：false=全部满足，true=任一满足
    .sorts([SortKey { .. }])
    .hidden(["owner"])
    .paged(50)
    .selected(selected_keys)
    .on_select(|keys, _window, cx| set_selection(keys, cx))
    .on_edit(|key, column, value, _window, cx| edit_cell(key, column, value, cx))
    .density(Density::Compact);
```

全部链式方法（`tables/options.rs:9-116`）：

| 方法 | 位置 | 说明 |
| --- | --- | --- |
| `rows(Rc<Vec<Row>>)` | `:32` | 数据行；用 `Rc` 便于与工具条共享 |
| `query(text)` | `:38` | 全局搜索词 |
| `filters(rules, any)` | `:44` | 筛选规则集合 |
| `sorts(keys)` | `:51` | 排序键 |
| `hidden(keys)` | `:60` | 隐藏列 |
| `paged(size)` | `:66` | 分页，每页行数 |
| `virtualized()` | `:73` | 虚拟化（行高必须一致） |
| `selected(keys)` | `:79` | 选中行 |
| `on_select(闭包)` | `:84` | 选择变化 |
| `detail(闭包)` | `:93` | 展开行详情 |
| `group_by(key)` | `:102` | 按某列分组 |
| `on_edit(闭包)` | `:108` | 单元格编辑 |
| `density(Density)` | `:116` | 行高密度 |

**四条渲染期断言**（`table.rs:100-150` 一带），违反会在开发期 panic：

1. 每行的 `Cell` 数必须等于列数；
2. `virtualized` 与 `detail` 不能同时开（虚拟化要求行高一致，展开行会破它）；
3. `group_by` 与 `paged` 不能同时开；
4. 有 `pinned` 列时不能 `virtualized` 或开 `detail`，且固定列**必须**给 `width`。

### 2.3 `Cell` 与 `Column`

`Cell`（`cell.rs:14`）是一个枚举，决定单元格怎么画：

```rust
Cell::Empty
Cell::Text("main.rs".into())
Cell::Number(1.2)
Cell::Tag("已修改".into(), Tone::Warning)     // 带语气的标签
Cell::Progress(0.42)                          // 0–1，画成带百分比的条
Cell::Spark(vec![1.0, 4.0, 2.0])              // 单元格里的迷你折线
Cell::Person("颜思齐".into())                  // 姓名 + 首字头像
```

`Column::new(key, title)`（`cell.rs:122`）的链式方法：`.width(Rems)`（`:140`）、`.end()`（`:146`，右对齐）、`.unsorted()`（`:152`）、`.decimals(n)`（`:157`）、`.prefix(..)` / `.suffix(..)`（`:162` / `:167`）、`.aggregate(Aggregate)`（`:173`，页脚给这一列算什么）、`.scale()`（`:179`，数值画成比例条）、`.editable()`（`:185`）、`.pinned()`（`:191`）。

### 2.4 树形表、透视表与表格工具条

```rust
TreeTable::new("tree-table", columns)
    .open(["src"])
    .child(TreeRow::new("src", [Cell::Text("src".into())])
        .children([TreeRow::new("src/main.rs", [Cell::Text("main.rs".into())])]));

PivotTable::new(["地区", "季度"], records)
    .pivot(row_field, column_field, value_field)
    .decimals(0);

TableToolbar::new("tools")
    .search(&query_state)
    .filter(|_window, cx| open_filter_builder(cx))
    .columns(|_window, cx| open_column_picker(cx))
    .density(|density, _window, cx| set_density(density, cx))
    .export(|_window, cx| to_csv(&columns, &rows));
```

`to_csv(&columns, &rows)`（`rules.rs:148`）直接给导出按钮用。

### 2.5 网格与电子表格

```rust
DataGrid::new("grid", ["列 A", "列 B"], Rc::new(rows_of_strings))
    .on_change(|(row, col), text, _window, cx| write(row, col, text, cx));

Spreadsheet::new("sheet", 200, 26)
    .cells(Rc::new(cell_map))                  // (行, 列) -> 文本
    .merge((0, 0), (0, 3))                     // 合并单元格
    .freeze(1, 1)                              // 冻结首行首列
    .on_change(|(row, col), text, _window, cx| commit(row, col, text, cx));
```

### 2.6 筛选与排序的构造面板

```rust
FilterBuilder::new("fb", [("name", "名称"), ("size", "大小")])
    .rules(existing_rules, false)
    .on_change(|rules, _window, cx| apply_filters(rules, cx));

SortBuilder::new("sb", [("name", "名称"), ("size", "大小")])
    .keys(existing_keys)
    .on_change(|keys, _window, cx| apply_sorts(keys, cx));
```

`FilterRule` 里的比较运算是 `Test`（`rules.rs:9`），它有 `.label()`（`:29`，取中文/英文文案）与 `.takes_value()`（`:41`，判断这个运算是否需要一个输入值）两个方法——做筛选 UI 时靠它决定是否显示输入框。

## 三、`charts` 用法

所有图表都是 `RenderOnce`，构造后直接 `.child()` 进树，且都实现了 `Styled`（可以用 `.h()` / `.w()` 控制尺寸）。

### 3.1 笛卡尔系（折线 / 面积 / 柱 / 散点）

```rust
LineChart::new("commits", ["周一", "周二", "周三", "周四", "周五"])
    .series(Series::new("提交", [3.0, 7.0, 5.0, 9.0, 6.0]))
    .series(Series::new("合并", [1.0, 2.0, 4.0, 3.0, 5.0]))
    .rule(6.0, "目标线")             // 一条水平参考线
    .note(3, "发布日")               // 给某个刻度加标注
    .zoom()                          // 允许框选缩放
    .format(|v| format!("{v:.0} 次")) // 数值格式化
    .smooth();                       // 仅 LineChart / AreaChart

BarChart::new("bars", labels).series(series).stacked().horizontal();
AreaChart::new("area", labels).series(series).stacked().smooth();

ScatterChart::new("scatter")
    .points(Points::new(points).sizes(sizes))
    .axes("耗时 (ms)", "内存 (MB)")
    .format(|v| format!("{v:.1}"));
```

导出：`.csv()` 拿 CSV 文本，`.svg(width, height, cx)` 拿 SVG 文本（`cartesian.rs:204` / `:209`）。

### 3.2 占比类

```rust
PieChart::new("langs")
    .slice("Rust", 62.0)
    .slice("TypeScript", 28.0)
    .slice("其他", 10.0)
    .donut("62%", "Rust");            // 变环形，中心显示一个大字与副标题

Sunburst::new("disk", [
    Slice::new("src", 40.0).children([Slice::new("menus", 12.0), Slice::new("forms", 28.0)]),
    Slice::new("assets", 8.0),
]);

Treemap::new("usage").tile("src", 40.0).tile("assets", 8.0).format(|v| format!("{v:.0} MB"));
FunnelChart::new("funnel").stage("访问", 1000.0).stage("注册", 240.0).stage("付费", 60.0);
```

### 3.3 分布与统计


### 3.7 配色

## 四、典型组合：一个带工具条的数据表 + 图表

```rust
v_stack()
    .gap_2()
    .child(TableToolbar::new("tools")
        .search(&query_state)
        .export(|_w, cx| export_csv(cx)))
    .child(DataTable::new("table", columns)
        .rows(rows)
        .query(query)
        .paged(50)
        .on_select(|keys, _w, cx| set_selection(keys, cx))
        .flex_1())
    .child(h_stack().gap_2()
        .child(LineChart::new("trend", labels).series(series))
        .child(PieChart::new("share").slice("Rust", 62.0).slice("TS", 28.0)))
```

## 五、写本域组件时的注意点

1. **大数据用 `paged` 或 `virtualized`**，但两者与 `detail` / `group_by` / `pinned` 有互斥断言，选之前先看第 2.2 节那四条。
2. 单元格的内容由 `Cell` 枚举决定，不要在业务侧自己拼"带标签的 div"——加新样式应当扩展 `Cell`。
3. 图表的数值格式化统一走 `.format(闭包)`，不要在图表里写死单位。
4. 图表颜色走 `colors.chart`，不要另外给色板。
5. 所有断言（方阵、至少三轴、至少两个值、`last > first` 等）都是开发期护栏，用来在数据错的那一刻报错，而不是画出一个错误的图。
