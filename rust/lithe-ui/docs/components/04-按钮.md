# 04 · 按钮（`buttons`）

按钮域只有一个"正主"（`Button`），其余都是在它之上拼出来的形态：图标预设、开关组、分段控件、二次确认、复制/分享、快速动作、动作条。

> 画廊对应 `examples/gallery/pages/buttons/`。

## 二、`Button` 完整用法

`Button` 是 `RenderOnce`，构造只需要一个 id：

```rust
Button::new("save")
    .label("保存")
    .variant(ButtonVariant::Primary)
    .size(Size::Medium)
    .icon(IconName::Save)
    .shortcut("cmd-s")
    .on_click(|_event, _window, cx| save(cx));
```

### 2.1 构造与内容

| 方法 | 位置 | 说明 |
| --- | --- | --- |
| `new(id)` | `button.rs:243` | 唯一入口，`id: impl Into<ElementId>` |
| `label(text)` | `:271` | 文字标签 |
| `aria_label(text)` | `:279` | 无障碍名；纯图标按钮必须给 |
| `icon(IconName)` | `:336` | 前置图标（内置图标集） |
| `icon_element(impl IntoElement)` | `:346` | 前置图标（宿主自己的图标元素） |
| `trailing_icon(IconName)` | `:351` | 后置图标，如展开箭头 |
| `child(...)` | `ParentElement` | 需要完全自定义内容时用 |

### 2.2 语气（variant）

`ButtonVariant`（`button.rs:73`）九种：`Primary`、`Secondary`（默认）、`Outline`、`Ghost`、`Subtle`、`Success`、`Danger`、`Link`、`Custom(ButtonCustomVariant)`。

每种语气在 `tone()`（`button.rs:88` 起）里被翻译成一组语义色，举例：

| 语气 | 底色 | 悬停 | 按下 / 选中 | 文字 | 边框 |
| --- | --- | --- | --- | --- | --- |
| `Primary` | `accent` | `accent_hover` | `accent_hover` 混 `on_accent` 0.12 | `on_accent` | 透明 |
| `Secondary` | `surface` | `hover` | `active` | `fg` | `border` |
| `Outline` | 透明 | `hover` | `active` | `fg` | `border_strong` |
| `Ghost` | 透明 | `hover` | `active` | `fg` | 透明 |
| `Subtle` | `hover` | `active` | `active` 混 `border_strong` 0.5 | `fg` | 透明 |

`Custom` 需要自己给一套颜色：

```rust
Button::new("brand")
    .label("升级")
    .custom(ButtonCustomVariant::new(cx)
        .color(brand_bg)
        .foreground(brand_fg)
        .hover(brand_hover)
        .active(brand_pressed)
        .shadow(true));
```

`ButtonCustomVariant::new(cx)`（`:32`）从当前主题取默认色，`.color` / `.foreground` / `.hover` / `.active` / `.shadow`（`:43`–`:66`）逐个覆写。

### 2.3 尺寸、状态与行为

| 方法 | 位置 | 说明 |
| --- | --- | --- |
| `size(Size)` | `:331` | `Size::XSmall` … `Size::Large`，高度走 `theme.control_height` |
| `primary()` | `:327` | `.variant(Primary)` 的简写 |
| `selected(bool)` | `:316` | 停在"按下"配色，用于"当前是这个模式" |
| `toggled(bool)` | `:322` | 明确的开关态 |
| `disabled(bool)` | `:369` | 禁用：吃 `fg_disabled`，不响应点击 |
| `loading(bool)` | `:375` | 原地转圈，**宽度不变**，仍可被 Tab 走到 |
| `full_width()` | `:380` | 撑满父容器 |
| `tooltip(text)` | `:299` | 悬停提示 |
| `shortcut("cmd-s")` | `:357` | 在按钮上显示快捷键，**写法不合法时 panic** |
| `tab_stop(bool)` | `:286` | 是否作为 Tab 停靠点 |
| `focus_handle(&FocusHandle)` | `:364` | 用宿主的句柄接管焦点（按钮会因模式切换而重建时用） |
| `debug_selector(closure)` | `:394` | 给 UI 测试通道一个稳定名字 |
| `on_click(closure)` | `:385` | 点击回调，第一个参数是 `&ClickEvent` |

`Button` 还实现了 `Styled`（`button.rs:524`），所以 `.bg()`、`.rounded()`、`.w()` 这类 gpui 链式方法都能继续用。

### 2.4 三个预设

```rust
close_button("close")            // IconName::X + tooltip "Close"
back_button("back")              // IconName::ArrowLeft + tooltip "Back"
more_button("more")              // IconName::Ellipsis + tooltip "More"
```

它们返回的就是 `Button`，可以继续链式覆盖（如 `.on_click(...)`）。提示文案目前是英文常量（`presets.rs:7-19`），需要中文时自己 `.tooltip(tr("..."))` 覆盖。

## 三、成组、切换与分段

### 3.1 `ButtonGroup`

```rust
ButtonGroup::new()
    .button(Button::new("left").label("左"))
    .button(Button::new("right").label("右"));
```

只负责拼接与统一圆角，选择逻辑由调用方持有。

### 3.2 `ToggleGroup` / `ToggleButton`

```rust
ToggleGroup::new("view-mode")
    .item(ToggleItem::new("list").label("列表").icon(IconName::List))
    .item(ToggleItem::new("grid").icon(IconName::Grid).tooltip("网格视图"))
    .selected(["list"])
    .multiple()                                  // 不加则单选
    .size(Size::Small)
    .on_change(|values, _window, cx| set_mode(values, cx));
```

- `ToggleItem::new(value)`（`group.rs:68`）有 `.label` / `.icon` / `.icon_element(闭包)` / `.tooltip`；只给图标时记得补 `.tooltip` 或让外层补 `aria_label`。
- `ToggleButton::new(id, item, on)`（`group.rs:181`）是单个开关：`.size()` / `.disabled()` / `.on_toggle(|on, window, cx| ...)`。

### 3.3 `SegmentedControl`

```rust
SegmentedControl::new("scope", "all")
    .segment("all", "全部", None)
    .segment("mine", "我的", Some(IconName::User))
    .size(Size::Medium)
    .on_change(|value, _window, cx| set_scope(value, cx));
```

`.segment(value, label, Option<IconName>)`（`segmented.rs:41`），选中块是整体滑动的指示层。

## 四、特殊用途按钮

### 4.1 二次确认：`ConfirmButton`

```rust
ConfirmButton::new("delete", "删除分支", ConfirmMode::Twice)
    .armed_label("再点一次确认删除")
    .size(Size::Small)
    .on_confirm(|_window, cx| delete_branch(cx));
```

`ConfirmMode::Hold` = 长按，`ConfirmMode::Twice` = 点两次；两种模式都有默认英文武装文案（`"Press again to confirm"` / `"Click again to confirm"`，`confirm.rs:57-60`），用 `.armed_label(..)` 换成中文。

### 4.2 复制与分享

```rust
CopyButton::new("copy-hash", &commit_sha);          // 点后短暂显示勾

ShareButton::new("share")
    .text("看看这段代码")
    .url("https://example.com/s/abc123");            // macOS 弹系统分享面板
```

`ShareButton` 在非 macOS 平台上没有原生面板；它的 `Picker`（`share.rs:109`，内部结构）只在 macOS 构建里出现，业务代码不要直接依赖。

### 4.3 悬浮按钮与快速动作

```rust
FloatingActionButton::new("new-doc", IconName::Plus)
    .label("新建")                                   // 有 label 时是展开式药丸
    .tooltip("新建文档")
    .on_click(|_e, _w, cx| new_doc(cx));

QuickActions::new("quick")
    .action(QuickAction::new(IconName::Play, "运行", |_w, cx| run(cx))
        .note("当前目标")
        .shortcut("cmd-r"))
    .action(QuickAction::new(IconName::Hammer, "构建", |_w, cx| build(cx)));
```

`QuickActions` 支持指针与方向键选择、Enter 或点击执行，适合面板右上角的"当前上下文能做什么"。

### 4.4 动作条与动作面板

```rust
// 选中若干行时出现
BulkActionBar::new("bulk", selected.len())
    .action(Button::new("bulk-delete").label("删除").variant(ButtonVariant::Danger))
    .on_clear(|_window, cx| clear_selection(cx));

// 普通上下文动作条，可浮在内容上
ActionBar::new().floating().child(Button::new("pin").icon(IconName::Pin));

// 动作面板（移动端式）
ActionSheet::new("sheet", |_window, cx| close(cx))
    .title("移动到")
    .message("选择一个目标文件夹")
    .action("收件箱", |_w, cx| move_to("inbox", cx))
    .destructive("删除", |_w, cx| remove(cx));
```

`ActionSheet::action(label, handler)`（`sheet.rs:52`）执行后自动关闭；`.destructive(..)`（`:62`）用危险语气渲染。


## 六、写按钮时的注意点

1. **颜色只从 `ButtonVariant` 和 `ButtonCustomVariant` 来**；组件内部全部经过 `tone()` 读 `Palette`，不要在调用处写死 `#xxxxxx`。
2. 纯图标按钮必须补 `aria_label` 或 `tooltip`，否则读屏与提示都缺失。
3. `.disabled(true)` 的按钮对对比度要求豁免（WCAG 对禁用控件不要求 4.5:1），但仍要能"看出是禁用的"——本库统一走 `fg_disabled`。
4. `.loading(true)` 会保持原宽度，避免布局跳动；它仍可被 Tab 走到，这是有意为之。
5. `.shortcut("...")` 与 `QuickAction::shortcut("...")` 都会对非法按键字符串 panic，键名要按 gpui 的写法（`cmd-s`、`ctrl-shift-p`）。
