# 07 · 导航（`navigation`）

导航域负责"怎么在内容之间走"：标签页、面包屑、命令面板、跳转、分页、目录、步骤条。

## 二、标签页

### 2.1 `Tabs`（内容区标签）

```rust
// tabs.rs:41
Tabs::new("settings-tabs", [Choice::new("general", "常规"), Choice::new("keys", "快捷键")], "keys")
    .placement(TabPlacement::Top)          // TabPlacement 枚举（tabs.rs:18）
    .panel(current_panel_element)          // 选中项对应的内容
    .on_change(|value, _window, cx| switch_tab(value, cx))
    .on_context(|value, _window, cx| open_tab_menu(value, cx));
```

- `tabs` 用 `Choice` 描述（可带图标与 `note`）；
- `.panel(..)` 只放"当前选中那页"的内容，组件不缓存其他页；
- `.on_context(..)` 是右键回调，通常用来弹 `TabOverflowMenu` 或行菜单。

### 2.2 `TabBar`（只要条）

```rust
TabBar::new("bar")
    .child(Tab::new(label_element).label("输出").aria_label("输出面板"))
    .child(Tab::new(error_element).label("问题").suffix(CountBadge::new(3)))
    .selected_index(0)
    .max_width(px(240.))                   // 单个标签的最大宽度
    .suffix(Button::new("more").icon(IconName::Ellipsis))
    .on_click(|index, _window, cx| select(index, cx));
```

`Tab::new(content)`（`tabs.rs:101`）放的是**标签里的内容元素**，`.label(text)`（`:115`）另给一个文字标签。

### 2.3 `EditorTabs`（编辑器专用）

```rust
EditorTabs::new("editor-tabs", [
    EditorTab::new("a.rs", "a.rs").icon(IconName::FileCode).dirty(true).pinned(true),
    EditorTab::new("b.rs", "b.rs").preview(true),
])
.selected("a.rs")
.on_select(|id, _w, cx| focus(id, cx))
.on_close(|id, _w, cx| close(id, cx))
.on_pin(|id, _w, cx| pin(id, cx))
.on_keep(|id, _w, cx| keep(id, cx))        // 预览态转常驻
.on_reorder(|from, to, _w, cx| move_tab(from, to, cx));
```

`EditorTab::new(id, title)`（`editor_tabs.rs:30`）的四个状态位：`.dirty(bool)`（未保存圆点）、`.pinned(bool)`（固定）、`.preview(bool)`（预览态，斜体）、`.icon(IconName)`。

### 2.4 标签溢出

```rust
TabOverflowMenu::new("overflow", hidden_tabs_as_choices)
    .selected("a.rs")
    .on_select(|value, _window, cx| focus(value, cx));
```

## 三、面包屑、侧边导航与导航菜单

### 3.1 `Breadcrumb`

```rust
Breadcrumb::new("path", [
    Crumb::new("src", "src").icon(IconName::Folder)
        .siblings([Choice::new("src", "src"), Choice::new("tests", "tests")]),
    Crumb::new("main.rs", "main.rs").icon(IconName::FileCode),
])
.on_select(|value, _window, cx| jump_to(value, cx));
```

`Crumb::new(value, label)`（`breadcrumb.rs:24`）的 `.siblings(..)`（`:39`）给这一级配一个同级下拉，点箭头就能横向切换。

### 3.2 `NavItem` / `NavGroup`

```rust
NavGroup::new("group-proj", "项目", true)
    .folded(false)
    .on_toggle(|open, _window, cx| fold(open, cx))
    .child(NavItem::new("files", IconName::Folder, "文件")
        .count("12")
        .active(true)
        .on_click(|_window, cx| show_files(cx)));
```

`NavItem::new(id, icon, label)`（`nav.rs:30`）有 `.count(..)`（右侧计数）、`.active(bool)`（当前项）、`.folded(bool)`（可折叠项是否收起）、`.on_click(..)`。
`NavGroup::new(id, title, open)`（`nav.rs:149`）有 `.folded(..)` 与 `.on_toggle(|open, window, cx| ..)`。

### 3.3 `NavigationMenu`

```rust
NavigationMenu::new("top-nav")
    .entry("产品", [Choice::new("editor", "编辑器").note("核心")])
    .entry("文档", [Choice::new("guide", "指南")])
    .on_select(|value, _window, cx| go(value, cx));
```

`.entry(label, links)`（`menu.rs:66`）：每一项是一组链接，`Choice` 的 `note` 会当作一行说明。

### 3.4 `BackForwardNavigation`


## 四、跳转与命令面板

### 4.1 `GoToLine`

```rust
GoToLine::new("goto", &line_state, buffer.line_count())
    .on_jump(|line, column, _window, cx| jump(line, column, cx));
```

- `new(id, state: &Entity<InputState>, lines: usize)`（`goto.rs:46`），`lines` 至少为 1，否则断言；
- `on_jump` 的回调签名是 `Fn(usize, Option<usize>, &mut Window, &mut App)`：行号 + 可选列号（支持 `12:8` 这类输入）。

### 4.2 `Command` 与 `CommandPalette`

```rust
CommandPalette::new("palette", |_window, cx| close(cx))
    .group("文件", [
        Command::new("file.new", "新建文件").icon(IconName::File).keys("cmd-n"),
        Command::new("file.save", "保存").keys("cmd-s"),
    ])
    .group("编辑", [Command::new("edit.find", "查找").keys("cmd-f")])
    .recent(["file.save"])
    .on_run(|value, _window, cx| run_command(value, cx));
```

- `Command::new(value, label)`（`kinds.rs:43`）：`.icon(IconName)`、`.icon_element(闭包)`（宿主自有图标，优先于 `icon`）、`.keys("secondary-shift-p")`（gpui 键语法，行尾用 `KbdCombo` 显示）。
- `CommandPalette::new(id, on_close)`（`kinds.rs:98`）：`on_close` 在 Escape / 点外面 / 执行某条后都会跑。
- `.group(title, commands)`（`kinds.rs:111`）分组；`.recent(values)`（`:122`）让最近用过的在查询为空时排在最前。
- 匹配是模糊匹配，命中的字母会被高亮标出。

### 4.3 另外三种面板

```rust
QuickOpen::new("open", |_window, cx| close(cx))
    .recent(["src/main.rs"])
    .on_open(|path, _window, cx| open(path, cx));

QuickSwitcher::new("switch", |_window, cx| close(cx))
    .on_switch(|value, _window, cx| switch_to(value, cx));

SearchPalette::new("search", |_window, cx| close(cx))
    .on_open(|value, _window, cx| reveal(value, cx));
```

### 4.4 `QuickLauncher`（独立窗口）

```rust
QuickLauncher::open(
    |query| search_everything(query),      // 返回 (分组标题, 该组命中项)
    |value, _window, cx| open(value, cx),
    cx,
)?;
```

`QuickLauncher::open(search, on_open, cx)`（`launcher.rs:26`）在**主屏幕居中、偏上五分之一处**开窗，尺寸取 `theme.palette_size()`。搜索回调返回 `Vec<(SharedString, Vec<Choice>)>`，即"分组 + 该组条目"。

## 五、分页、步骤与目录

### 5.1 `Pagination` / `LoadMore`

```rust
Pagination::new("pages", current_page, total_pages)
    .near(2)                               // 当前页左右各留几个页码
    .on_change(|page, _window, cx| load_page(page, cx));

LoadMore::new("more", loading)
    .shown(items.len(), total_count)
    .on_load(|_window, cx| load_more(cx));
```

### 5.2 `Steps` / `Wizard`

```rust
Steps::new("steps", [Choice::new("one", "基本信息"), Choice::new("two", "确认")], 0)
    .vertical()                             // 竖排
    .on_select(|index, _window, cx| goto_step(index, cx));

Wizard::new("wizard", step_choices, 0)
    .content(step_body.clone())             // 当前步的内容
    .ready(valid)                           // "下一步"是否可用
    .on_step(|index, _window, cx| goto_step(index, cx))
    .on_finish(|_window, cx| finish(cx));
```

两者的 `new(id, steps, current)`（`steps.rs:31` / `:225`）都会断言 `current < steps.len()`。

### 5.3 `TableOfContents`

```rust
let sections = cx.new(|_| Sections::new(scroll_handle));

TableOfContents::new("toc", &sections)
    .entry("intro", "简介", 0)
    .entry("install", "安装", 1)
    .entry("usage", "用法", 1);

// 文章里把每个标题注册成锚点
Anchor::new(&sections, "intro");
```

- `Sections::new(scroll: ScrollHandle)`（`toc.rs:21`）持有滚动句柄，目录能跟随滚动高亮当前章节；
- `Anchor::new(&sections, value)`（`toc.rs:52`）放在标题处，把它登记进目录；
- `TableOfContents::new(id, &sections)`（`toc.rs:104`）+ `.entry(value, label, depth)`（`:113`），`depth` 从 0 起。

```rust
    .child(
        v_stack().flex_1()
            .child(Breadcrumb::new("crumb", crumbs))

```

## 七、写导航组件时的注意点

1. 标签/导航项的"当前项"必须由调用方持有并传入（`selected` / `active`），组件不自己记状态。
2. 命令面板里的快捷键用 `Command::keys(..)`，键名走 gpui 语法（`cmd-n`、`secondary-shift-p`），显示统一用 `KbdCombo`。
3. `GoToLine` / `Steps` / `Wizard` / `BackForwardNavigation` 的构造里都有断言（越界、空集合），这是开发期护栏。
4. 目录要跟滚动联动，必须把**同一个** `ScrollHandle` 交给 `Sections` 与滚动容器。
5. 命令面板、快速打开这类"临时浮层"要能 Escape 关闭并把焦点还给原来的控件，`on_close` 就是为此存在的。
