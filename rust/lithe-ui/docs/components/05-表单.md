# 05 · 表单（`forms`）

`forms` 是组件库里最大的域：四十多个文件，覆盖文本输入、选择、数值、日期、颜色、文件上传，以及把它们组织成表单的骨架件。**快捷键录制控件 `HotkeyInput` 就在本域**（见 7.3）。

> 画廊对应 `examples/gallery/pages/forms/`。

## 二、底座：`InputState`（必须先看这一节）

所有文本类控件都不自己存文本，而是共享一个 `InputState` 实体（`forms/text/mod.rs:88`）。这是本域最重要的类型。

```rust
let state = cx.new(|cx| InputState::new(window, cx));
```

### 2.1 构造期的链式方法

| 方法 | 位置 | 说明 |
| --- | --- | --- |
| `multi_line(min, max)` | `:133` | 变成多行，给最小/最大行数 |
| `placeholder(text)` | `:139` | 占位文案 |
| `masked()` | `:145` | 掩码显示（密码） |
| `filter(闭包)` | `:151` | 字符级过滤，`allow: Fn(char) -> bool` |
| `max_len(len)` | `:157` | 最大长度 |
| `highlighter(...)` | `:163` | 挂高亮器（`CodeInput` / `JsonInput` / `RegexInput` 内部也在用） |

### 2.2 运行期的读写（`&mut Context<Self>`）

| 方法 | 位置 | 说明 |
| --- | --- | --- |
| `text()` / `is_empty()` | `:171` / `:175` | 读当前文本 |
| `set_text(text, cx)` | `:228` | 整体替换 |
| `insert(text, cx)` | `:248` | 在光标处插入 |
| `select(range, cx)` | `:252` | 设置选区 |
| `cursor()` / `selection()` | `:203` / `:199` | 读光标与选区 |
| `set_placeholder` / `set_masked` / `set_disabled` | `:211` / `:216` / `:221` | 运行期改状态 |

| `undo` / `redo` / `can_undo` / `can_redo` | `text/edit.rs:130` / `:137` / `:122` / `:126` | 撤销栈（`History`） |

### 2.3 事件与辅助类型

- `InputEvent`（`text/mod.rs` 导出）：输入框对外发出的事件（插入、删除、提交、上下方向键等）。
- `Highlight`（`text/highlight.rs:15`）：`Highlight::new(color)` 描述一段高亮。
- 按键动作 `Enter` / `Submit` / `Undo` / `Redo` / `Up` / `Down` / `Backspace` 属于 `pub(crate)`，`lithe_ui::init(cx)` 里通过 `forms::bind_keys` 统一绑定，业务代码不需要自己绑。

## 三、文本输入的常见用法

### 3.1 基础输入框

```rust
let name = cx.new(|cx| InputState::new(window, cx).placeholder("项目名"));

Input::new(&name)
    .size(Size::Medium)
    .prefix(Icon::new(IconName::Folder).size(IconSize::Sm))
    .suffix(Button::new("clear").icon(IconName::X))
    .clearable()                       // 有内容时显示清除按钮
    .invalid(!valid)                   // 错误态：边框转危险色
    .aria_label("项目名")
```

`PasswordInput::new(&state)`（`:185`）默认掩码，也有 `.size()`。

### 3.2 拼装：`InputGroup` / `InputAddon`

```rust
InputGroup::new(&state)
    .child(InputAddon::new(div().child("https://")))
    .child(Input::new(&state))
    .child(InputAddon::new(Button::new("go").label("前往")));
```

`InputAddon::new(body)`（`group.rs:22`）接受任意元素；`InputGroup::new(state)`（`:45`）把它们在视觉上连成一个控件。

### 3.3 搜索、就地编辑、路径

```rust
SearchInput::new("search", &query)
    .history(["src/main.rs", "src/lib.rs"])
    .size(Size::Small)
    .on_pick(|text, _window, cx| open(text, cx));

InlineEdit::new("title", "未命名")
    .placeholder("起个名字")
    .on_commit(|text, _window, cx| rename(text, cx));

PathInput::new("dir", &path).directories();     // 只选目录
```

### 3.4 带高亮的输入

```rust
// JSON：内置 json_highlights 高亮器
JsonInput::new(&json_state);
// 代码：CodeInput::new(&state).size(Size::Large)
// 正则：RegexInput::new(&state)，配 regex_highlights
// 表达式：ExpressionInput::new(&state)，求值用 evaluate(...)
```

`code_highlights` / `json_highlights` / `expression_highlights` / `regex_highlights` 都是本域导出的高亮函数，可以直接给 `InputState::highlighter(..)` 用，做自定义输入器时不必重写。

### 3.5 校验与掩码

```rust
EmailInput::new(&email_state);                  // 内部用 is_email
UrlInput::new(&url_state);                      // 内部用 is_url

PhoneInput::new("phone", &phone_state, "CN");   // country 必须是 COUNTRIES 里的码，否则断言失败
MaskedInput::new("card", &card_state, "#### #### #### ####");

TagInput::new("tags", ["rust", "gpui"])
    .placeholder("添加标签")
    .check(|text| text.len() <= 24)             // 校验失败的标签标红
    .suggestions([Choice::new("rust", "Rust")])
    .on_change(|tags, _window, cx| save_tags(tags, cx));

PinInput::new("otp", 6)
    .attempt(2)                                 // 第几次尝试（用于错误态）
    .letters()                                  // 允许字母
    .masked()
    .on_complete(|code, _window, cx| verify(code, cx));
```

### 4.1 `Choice`：所有选择控件的统一选项模型

### 4.2 下拉、组合框、多选

```rust

    .selected("system")
    .placeholder("选择主题")
    .size(Size::Medium)
    .disabled(false)
    .on_change(|value, _window, cx| set_theme(value, cx));

Combobox::new("font", &query_state, font_choices)
    .selected("JetBrains Mono")
    .free()                             // 允许输入不在列表里的值
```

### 4.3 复选框、单选、开关

```rust
Checkbox::new("agree")
    .checked(CheckState::Mixed)           // 半选；也接受 bool（From<bool> 转 On/Off）
    .label("我已阅读协议")
    .disabled(false)
    .on_change(|on, _window, cx| set_agree(on, cx));

CheckboxGroup::new("scopes", scope_choices)
    .selected(["read"])
    .on_change(|values, _window, cx| set_scopes(values, cx));

RadioGroup::new("mode", [Choice::new("a", "A"), Choice::new("b", "B")])
    .selected("a")
    .horizontal()                          // 横向排列
    .on_change(|value, _window, cx| set_mode(value, cx));

Switch::new("autosave")
    .checked(true)
    .label("自动保存")
    .on_change(|on, _window, cx| set_autosave(on, cx));
```

`CheckState`（`check.rs:21`）三态是 **`Off` / `On` / `Mixed`**（`Mixed` 就是"部分子项被选中"的半选态）。注意**不叫** `Checked` / `Unchecked` / `Indeterminate`。布尔值走 `From<bool>`：真得 `On`，假得 `Off`。

## 七、快捷键录制：`HotkeyInput`（用户点名的那一条）

### 7.1 它在整条链里的位置

```
typography::Kbd / KbdCombo    显示一个键帽（只读）
forms::HotkeyInput            录制一个键（本文件）
editor::KeybindingsEditor     整张快捷键表的编辑（含搜索与冲突检测）
settings::KeyboardShortcutsList  设置里只读的快捷键清单
```

### 7.3 用法

```rust
HotkeyInput::new("bind-save", binding.keys.clone())
    .on_change(|keystroke, _window, cx| {
        match keystroke {
            Some(stroke) => rebind("save", stroke, cx),
            None => unbind("save", cx),
        }
    })
```

行为（读 `hotkey.rs:49-105`）：

- 聚焦即进入录制态，显示"Press a shortcut…"；
- 按下任意键 → 立刻 `blur`，`on_change` 收到 `Some(Keystroke)`（组件把 `key_char` 置为 `None`，只保留规范化的键名与修饰键）；
- `Backspace` / `Delete`（无修饰键）→ `on_change(None)`，即清空；
- `Escape`（无修饰键）→ 直接 `blur`，**不触发** `on_change`；
- 未录制时显示 `KbdCombo::new(&stroke.unparse())`，空值时显示 "None"；行尾固定一个 `IconName::Keyboard`。

> 组件的提示文案（"Press a shortcut…" / "None"）目前是英文常量（`hotkey.rs:76` / `:81`）。要做中文界面时，这两个字符串应当走 `tr(key)` 从 `locales/ui.yml` 取，与组件库其余文案一致。

## 九、写表单组件时的注意点

1. **文本永远存在 `InputState` 里**，组件本身不持有文本；不要把输入框当成"值"，要当成"值的视图"。
2. 弹出面板一律走 `options::surface()`，不要各自写圆角与阴影。
3. 校验失败用 `.invalid(true)` / `FormField::error(..)`，颜色走 `danger` 系列 token。
4. 数字控件的 `range` / `step` 有断言，是开发期护栏，不是运行期分支。
5. 上传进度必须是 0–1 的 `f32`；`UploadList` 会断言。
6. 组件内的英文提示文案（占位符、"Press a shortcut…" 等）若要面向中文用户，应改为 `tr(key)` 并补 `locales/ui.yml`。
