### Tooltip

```rust
Tooltip::text("保存当前文件");                     // 给 div 的 .tooltip() 用
Tooltip::with_meta("保存", "secondary-s");         // 带快捷键
Tooltip::rich(|cx| some_view(cx));                 // 自定义内容
TooltipTrigger::new("tip", "说明").delay(Duration::from_millis(400)).follow_mouse();

```

`TooltipTrigger::new(id, text)` 自带延迟与跟随指针；`HelpTooltip` 是一个"?"标记。

### Kbd / KbdCombo（快捷键显示）

```rust
pub fn new(source: &str) -> Self   // src/typography/inline.rs:67 (Kbd) / :92 (KbdCombo)
```

- 参数是 **gpui 键位语法**：`"secondary-s"` 在 Mac 显示 ⌘S，其它平台显示 Ctrl+S；`"cmd-k cmd-s"` 这种空格分隔的是和弦，`KbdCombo` 会画成两段。
- 平台显示差异由 `Theme::platform` 决定，非 Mac 平台会在键之间画 `+`。

```rust
Kbd::new("secondary-s");
KbdCombo::new("cmd-shift-p");
KbdCombo::new(&keystroke.unparse());   // 把录到的 Keystroke 直接显示出来
```

菜单行、快捷键列表、按钮提示都复用它：`menus/draw.rs:97`、`settings/shortcuts.rs:94`、`buttons/button.rs:357`。

### 动效

```rust
Spinner::new("spin").style(SpinnerStyle::Dots);
Skeleton::new("sk");                                   // 用内容同尺寸占位
SkeletonText::new("sk-text", 3);
SkeletonCard::new("sk-card");
ProgressRing::new("ring", 0.6).child(div().child("60%"));
ProgressBar::new("bar", 0.6).buffer(0.8);

Transition::new("panel", shown).entrance(Entrance::Rise).child(panel);
Stagger::new("list").step(Duration::from_millis(40)).children(rows);
AnimatePresence::new("rows").on_gone(|key, _, cx| { /* 可以真正移除了 */ });
Reorder::new("rows").on_reorder(|from, to, _, cx| {});

Flash::new("cell", value_version).child(cell);   // key 一变就闪一下
Shake::new("field", attempt).child(field);       // 输入被拒时抖一下
Confetti::new("confetti", bursts);
```

`reduced_motion` 打开时，`Shake` / `Marquee` / `Confetti` / `Shimmer` / `Spinner` 都会静止或停在某一帧——组件自己处理，调用方不用判断。
