# 08 · 列表与数据展示（`lists` / `data_display`）

`lists` 管"一排行"：普通列表、树、虚拟长列表、可选可排可滑的列表。`data_display` 管"把一个值展示出来"：头像、徽标、统计、进度、时间线、二维码等小件。

> 画廊对应 `examples/gallery/pages/lists/`、`examples/gallery/pages/data_display/`。

## 二、`lists` 用法

### 2.1 基础列表：`List` + `ListItem`

```rust
List::new()
    .divided()                                  // 行间加分隔线
    .child(ListItem::new("row-1", "main.rs")
        .description("入口")
        .detail("1.2 KB")
        .leading(Icon::new(IconName::FileCode))
        .trailing(Button::new("row-1-more").icon(IconName::Ellipsis))
        .selected(true)
        .on_click(|_window, cx| open("main.rs", cx)));
```

`ListItem::new(id, title)`（`item.rs:36`）的全部链式方法：

| 方法 | 位置 | 说明 |
| --- | --- | --- |
| `strong` / `quiet` / `struck` | `:55` / `:61` / `:67` | 标题加粗 / 弱化 / 加删除线 |
| `description(text)` | `:73` | 标题下的副文案 |
| `detail(text)` | `:79` | 行尾的安静信息（大小、时间） |
| `leading(element)` / `trailing(element)` | `:85` / `:91` | 行首 / 行尾放任意元素 |
| `selected(bool)` | `:96` | 选中态 |
| `current(bool)` | `:102` | "当前项"（与 selected 不同的语义，如光标所在行） |
| `disabled(bool)` | `:107` | 禁用 |
| `on_click(闭包)` | `:121` | 点击回调 |

### 2.2 选择、排序、侧滑

```rust
SelectableList::new("files")

    .row("two", ListItem::new("2", "第二项"))
    .on_reorder(|keys, _window, cx| reorder(keys, cx));

SwipeableListItem::new("row", ListItem::new("m", "一封邮件"))
    .action(SwipeAction::new("归档", IconName::Archive, |_w, cx| archive(cx)))
    .action(SwipeAction::new("删除", IconName::Trash, |_w, cx| remove(cx)).tone(Tone::Danger));
```

### 2.4 树：`Tree` / `TreeNode`

```rust
Tree::new("tree", [
    TreeNode::new("src", "src")
        .icon(IconName::Folder)
        .children([
            TreeNode::new("src/main.rs", "main.rs").icon(IconName::FileCode),
            TreeNode::new("src/lib.rs", "lib.rs"),
        ]),
    TreeNode::new("tests", "tests").pending(),     // 懒加载占位
])
.open(["src"])
.selected(["src/main.rs"])
.multiple()
.on_select(|keys, _window, cx| select(keys, cx))
.on_activate(|key, _window, cx| open(key, cx))
.on_load(|key, _window, cx| load_children(key, cx))
.on_rename(|key, name, _window, cx| rename(key, name, cx))
.on_move(|key, target, at: DropAt, _window, cx| move_node(key, target, at, cx));
```

`TreeNode::new(key, label)`（`tree/model.rs:29`）还有 `.note(..)`（行尾说明）、`.tone(Tone)`、`.icon(IconName)`、`.child(node)` / `.children(nodes)`、`.pending()`。
`DropAt`（`tree/model.rs:251`）描述拖放的落点：目标之前 / 之后 / 之内。

键盘行为（`tree/mod.rs:50` 的文档注释）：`Right`/`Left` 展开、收起与上溯；`Up`/`Down` 行走；`Enter` 展开节点或激活叶；`F2` 重命名；开启 `multiple` 时 Cmd / Shift 扩展选择；给了 `checked` 时复选框会连带整棵子树。**树需要外部给它一个高度**（不给就量不到可见行）。

## 三、`data_display` 用法

### 3.1 头像与徽标

```rust
Avatar::new("me", "颜思齐")
    .image(image_source)               // 有图用图，无图显示首字
    .size(AvatarSize::Md)
    .square()                          // 方形（默认圆形）
    .ring().ring_color(colors.accent)
    .presence(Presence::Online);

AvatarGroup::new(avatars).max(5).size(AvatarSize::Sm);
UserChip::new("chip", "颜思齐").image(avatar_source);

Badge::new("Beta").tone(Tone::Info).dot(true);
CountBadge::new("unread", 12).max(99).over(icon_element);
DotBadge::new().tone(Tone::Success).over(avatar_element);
```

`Presence` 是在线状态枚举（`Online` / `Away` / `Busy` / `Offline` 一类）；`Tone` 是通用语气枚举，徽标、标签、时间线、树行共用。

## 五、写本域组件时的注意点

1. **列表不持有数据**：`rows` / `row(..)` 吃的是调用方给的 `ListItem`，选中项由调用方传入并回写。
2. 长列表必须虚拟化（`VirtualList`）或分页（`InfiniteList`），不要在 `List` 里塞几千行。
3. `Tree` 必须被给一个高度，否则量不到可见行；懒加载节点用 `TreeNode::pending()` 配合 `on_load`。
4. 一行的"语气"统一走 `Tone`，不要在行内写死颜色。
5. 阈值类组件（`Meter` / `Gauge`）用 `thresholds(warn, danger)` 而不是调用方自己判断颜色。
6. `QrCode` / `Barcode` 的构造返回 `Result`，错误类型分别是 `QrError` / `BarcodeError`，调用方要处理。
