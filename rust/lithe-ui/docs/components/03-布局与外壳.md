# 03 · 布局与外壳（`layout` / `shell`）

本域负责"东西摆在哪"。`layout` 是可复用的布局容器与分栏机制，`shell` 是窗口外壳（标题栏、工具栏、状态栏、标签栏、活动栏、窗口管理）。两者都只管结构，不管业务。

> 本域组件在画廊里对应 `examples/gallery/pages/layout/`、`examples/gallery/pages/shell/`。

## 二、`layout` 域用法

### 2.1 起步：`h_stack` / `v_stack`

几乎所有布局都是从这两个函数开始的，它们返回 GPUI 的 `Div`，因此 gpui 的链式方法全部可用：

```rust
use lithe_ui::layout::{h_stack, v_stack};

v_stack()
    .gap_2()
    .p_4()
    .child("标题")
    .child(h_stack().gap_1().child(Button::new("ok").label("确定")));
```

- `ZStack::new()`：层叠，子元素按加入顺序叠放，常用于把浮层压在内容上。
- `Container::new(ContainerSize::Md)`：按主题里的容器宽度 token 居中。
- `AspectRatio::new(16.0 / 9.0)`：把子元素锁在这个宽高比里。

### 2.2 分栏：`SplitPane`

```rust
use lithe_ui::layout::SplitPane;
use gpui::Axis;

SplitPane::new("editor-split", Axis::Horizontal, px(220.))
    .sizes(&[0.28, 0.72])                       // 初始比例
    .pane(sidebar_view.clone())                 // 逐格加入，顺序即布局顺序
    .pane(editor_view.clone())
    .on_resize(|sizes, _window, cx| {           // 拖完回调最终比例
        log::info!("sizes = {sizes:?}");
    })
```

- `min` 参数是每格的最小像素，拖拽不会把格子压到比它更小。
- 只想要手柄而不想自己算比例时，用自由函数 `resize_handle(id, axis, cx)` / `resize_edge(id, axis, cx)` 自行拼装。

### 2.3 滚动：`ScrollArea` / `Scrollbar` / 滚动辅助件

```rust
let handle = ScrollHandle::new();

ScrollArea::new("log-scroll")
    .shadows()                                  // 边缘渐隐
    .child(ScrollShadow::new(&handle))          // 只吃 handle，不占布局格
    .child(log_view.clone())
```

- `Scrollbar::new(id, &handle, Axis::Vertical).presence(0.6)`：用 `presence`（0–1）控制不滚动时的可见度。
- `ScrollToTop::new(id, &handle)`：跟随同一个 `ScrollHandle`，滚出顶部后出现回顶按钮。
- `StickyHeader::new(id, &handle, |window, cx| header(window, cx))`：表头由闭包给出，滚动时吸顶，`.child(...)` 放正文。
- 三者都读同一个 `ScrollHandle`，所以它们必须放在同一个滚动容器里。
- `on_axis(element)`：把滚动条那套样式套到自定义元素上。

### 2.4 停靠面板：`Dock`（实体视图）

`Dock` 是本域唯一的重组件，它是 `Render` 实体，不能直接放进元素树，要 `.clone()`：

```rust
let dock = cx.new(|cx| {
    Dock::new(
        |_window, _cx| editor_area.into_any_element(),          // 中央区
        |id, _window, _cx| panel_body(id).into_any_element(),   // 每个面板的内容
        cx,
    )
});

dock.update(cx, |dock, cx| {
    dock.add(DockPanel::new("project", PanelTitle::Plain("项目".into()), IconName::Folder), DockSide::Left);
    dock.add(DockPanel::plain("terminal", "终端"), DockSide::Bottom);
});
```

常用方法（`layout/dock/mod.rs:215-401`）：

| 方法 | 作用 |
| --- | --- |
| `add(panel, side)` | 把面板加到某一边 |
| `set_side_limits(side, limits)` / `set_side_limits_with(...)` | 设置某边的最小 / 最大 / 预留尺寸 |
| `size(side)` / `set_size(side, size, cx)` | 读写某边当前尺寸 |
| `hide(id, cx)` / `show(id, cx)` / `toggle(id, cx)` / `is_hidden(id)` | 面板显隐 |
| `activate(id, cx)` | 激活并展开某面板 |
| `move_panel(id, spot, cx)` | 把面板挪到 `Spot` 指定的落点 |
| `layout()` / `restore(&layout, cx)` | 取快照 / 还原快照 |

`PanelTitle` 是"可解析标题"：面板标题可能需要国际化或延迟取用，`resolve(cx)`（`:105`）会把它变成最终的 `SharedString`；不需要时直接用 `PanelTitle::Plain` 或快捷构造 `DockPanel::plain(id, title)`（`:138`，无图标）。

### 2.5 网格、页面骨架与表面

```rust
// 等宽网格：每列不小于 220px，间距 12px，能放几列放几列
SimpleGrid::new("grid", px(220.), px(12.)).child(...).child(...);

// 瀑布流：固定 3 列，间距 12px，元素往最短的一列塞

// 页面头
Page::new("设置")
    .subtitle("编辑器与外观")
    .action(Button::new("reset").label("恢复默认"));

// 整体骨架
AppShell::new()
    .title_bar(TitleBar::new("title").title("Lithe"))
    .sidebar(Sidebar::new("side", false).child(tree.clone()))
    .status_bar(StatusBar::new().left(StatusBarItem::new("branch").label("main")))
    .child(main_area);

// 主从（内部即 SplitPane，0.36 / 0.64）
MasterDetail::new("md", list_view.clone(), detail_view.clone(), px(240.));
```

表面件（`Card` / `Panel` / `Section` / `Well` / `Fieldset` / `Frame`）都实现 `ParentElement`，构造后直接 `.child(...)`：

```rust

    .header(CardHeader::new("构建").description("最近一次：3 分 12 秒").action(Button::new("rerun")))
    .child(build_log.clone())
    .footer(Button::new("more").label("查看全部"));

```

### 2.6 折叠、抽屉、浮窗、视口

```rust
// 手风琴：.multiple() 允许多开，.first_open() 默认展开第一项
Accordion::new("acc")
    .first_open()
    .item(AccordionItem::new("编辑器").child(font_settings.clone()))
    .item(AccordionItem::new("快捷键").child(kbd_editor.clone()));

// 单块折叠
Collapsible::new("adv", false).child(advanced_options.clone());

// 右侧抽屉（side 必须是边，不能是 Place::Center，构造里会 assert）
Sheet::new("sheet", Place::Right, "筛选", |_window, cx| close(cx))
    .child(filter_form.clone());
Drawer::new("drawer", |_window, cx| close(cx)).child(body.clone());

// 可拖动浮窗
FloatingPanel::new("float", "查找", point(px(320.), px(160.)))
    .actions([Button::new("pin").icon(IconName::Pin)])
    .on_move(|origin, _window, _cx| { /* 落点 */ })
    .child(search_body.clone());

// 可缩放视口（默认 0.1–8 倍）
Viewport::new("canvas-vp", |t, window, cx| canvas_body(t, window, cx))
    .zoom_range(0.25, 4.0);
```

### 2.7 布局持久化：`Workspace`

```rust
let snap = Workspace::capture(&dock.read(cx), &panes.read(cx));
let json = snap.to_json();
// 下次启动
let snap = Workspace::from_json(&json)?;
snap.apply(&dock, &panes, cx);
```

常量 `WORKSPACE_VERSION`（`layout/mod.rs` 导出）用于快照版本判断，格式变更时要升它并在 `from_json` 里做兼容。

## 三、`shell` 域用法

### 3.1 标题栏与窗口控制

```rust
use lithe_ui::shell::{TitleBar, WindowControls, drag_region};
use lithe_ui::primitives::Platform;

TitleBar::new("title")
    .title("Lithe — my-app")
    .platform(Platform::Windows)                 // 决定三键在左还是在右
    .on_close(|_window, cx| cx.quit())
    .action(Button::new("share").icon(IconName::Share));
```

- `WindowControls::new(id).platform(..).on_close(..)`：只要三键时单独用。
- `drag_region(id, window, cx)`：把某块区域标记为可拖动窗口（无边框窗口必需）。
- `TitleBar::window_options(cx)`（`chrome.rs:317`）返回与外壳匹配的 `WindowOptions`，开窗时直接用它，避免每处重复写窗口参数。

> **配色提示**：标题栏底色取自 `cx.theme().colors.title_bar`，它与页面底色 `bg` 是两个不同的槽位；本库默认值里两者可能相等，宿主（如 `lithe-gpui` 的 workbench）可以单独覆盖 `title_bar` 让外壳与内容分层。

### 3.2 工具栏与状态栏

```rust
Toolbar::new()
    .child(ToolbarGroup::new()
        .child(Button::new("build").icon(IconName::Hammer))
        .child(Button::new("run").icon(IconName::Play)))
    .child(ToolbarSeparator)                    // 单元结构体，直接当元素用，没有 new()
    .child(ToolbarGroup::new().child(Button::new("debug").icon(IconName::Bug)));

StatusBar::new()
    .left(StatusBarItem::new("branch")
        .icon(IconName::GitBranch)
        .label("main")
        .tooltip("切换分支")
        .on_click(|_window, cx| open_branch_picker(cx)))
    .right(ZoomControl::new("zoom"));
```

- `StatusBarItem` 支持 `leading`（放自定义元素）、`icon`、`label`、`tooltip`、`on_click` 五个链式方法（`bars.rs:214-234`）。
- `ZoomControl::new(id)` 内部通过 `Theme::update` 改 `font_scale`，再由 `Theme::apply_rem` 统一作用到窗口 rem —— **缩放只有这一个杠杆**，不要在组件里乘系数。

### 3.6 窗口管理

```rust
// 打开一个由 lithe 托管边框的窗口
open_hosted::<MyView>(cx)?;

// 迷你窗：固定在屏幕某个角，或居中（corner = None）
MiniWindow::open("快速预览", size(px(420.), px(280.)), Some(Corner::BottomRight), view.into(), cx)?;

// 窗口清单与聚焦
let all = WindowManager::windows(cx);
WindowManager::focus(all[0].0, cx)?;
```

`WindowRoot`（`shell/host/root.rs:30`）是"窗口根"，负责图层栈：

```rust
let root = cx.new(|cx| WindowRoot::new(view.into(), window, cx));
root.update(cx, |root, cx| {
    root.push_layer(layer_element, window, cx);
    root.push_dialog(dialog_element, window, cx);
    let id = root.push_toast(Toast::new("已保存"), cx);
    root.pop_layer(window, cx);
});
```

`open_rooted_window(...)` 一步建立带 `WindowRoot` 的窗口；`dismiss_hosted(window, cx)` 关掉当前最上层。

### 3.7 原生集成

```rust
// symbol 是 SF Symbol 名；非 macOS 构建下 new() 会返回 Err（"tray icons need macOS"）
let tray = TrayIcon::new(
    "square.and.pencil",
    vec![TrayItem::Action("打开".into()), TrayItem::Separator, TrayItem::Action("退出".into())],
    |index, cx| log::info!("picked {index}"),
    cx,
)?;
tray.pick(0);                 // 等价于点了第一项
set_dock_badge(Some("3"))?;   // Dock 角标
let badge = dock_badge()?;
```

`TrayIcon` 被 drop 时托盘图标自动移除，所以要把它存在 App 状态里而不是临时变量里。

`ResizeBorder::new()`（自绘缩放边）与 `Vibrancy::new()`（毛玻璃底层）通常与无边框窗口搭配使用。

## 四、典型组合：一个 IDE 主窗口骨架

```rust
v_stack()
    .size_full()
    .bg(cx.theme().colors.bg)
    .child(
        TitleBar::new("title")
            .title("Lithe — demo")
            .platform(Platform::Windows)
            .on_close(|_window, cx| cx.quit()),
    )
    .child(
        h_stack()
            .flex_1()
            .min_h_0()
            .child(ActivityBar::new("activity")
                .item(ActivityItem::new("files", IconName::Folder, "文件"))
                .selected("files"))
            .child(dock.clone())                     // Dock 实体：项目树 / 终端 / 主编辑区
            .child(Sidebar::new("inspector", false).child(inspector.clone())),
    )
    .child(
        StatusBar::new()
            .left(StatusBarItem::new("branch").icon(IconName::GitBranch).label("main"))
            .right(OfflineIndicator::new("net", Connectivity::Online))
            .right(ZoomControl::new("zoom")),
    )
```

## 五、写本域组件时的注意点

1. `Dock`、`PaneGroup` 是实体视图（`Render`），其余布局件基本都是 `RenderOnce`，一次性渲染，不需要实体。
2. 布局只管结构，**不写颜色**：需要底色时在调用处传 token，表面件内部统一走 `surface` / `bg` / `border`。
3. 尺寸一律用 `cx.theme()` 的 token（`control_height`、`sidebar_width`、`pane_min`、`window_margin`），不要写常量像素。
4. 会持久化的东西（`Dock` 布局、`Workspace` 快照、`SplitPane` 比例）都要能被读回，改结构时同步 `WORKSPACE_VERSION`。
