> 画廊对应 `examples/gallery/pages/git/`、`pages/project/`、`pages/files/`、`pages/collab/`、`pages/chat/`、`pages/messaging/`、`pages/agent/`。

## 二、`git` 用法

### 2.1 看差异

```rust
DiffViewer::new("diff", stretches)
    .layout(DiffLayout::Split)                  // 或 Inline
    .headless()                                  // 不要文件头
    .open(opened_stretches)
    .on_open(|index, _window, cx| toggle(index, cx))
    .on_layout(|layout, _window, cx| set_layout(layout, cx));
```

差异底层是三个自由函数：`diff(old, new)` 生成差异、`pairs(..)` 做行配对、`stat(..)` 算增删统计；`DiffStat::new(added, removed)`（`badges.rs:56`）把统计画成 `+n -m`。

`FileExplorer::new` 有一条重要断言（`explorer.rs:62`）：**路径层数必须等于给出的层级数**，且除第一层外，每一层的名字必须能在上一层的文件夹里找到。传错了说明调用方的数据本身不一致。

## 九、写本域组件时的注意点

1. 协同一人的颜色由 `Peer` 的 `hue` 决定（`peers.rs:38`），同一人在光标、选区、头像里必须同色——不要各自取色。
2. 差异与冲突的底层是自由函数（`diff` / `pairs` / `stat` / `conflicts` / `regions` / `resolve`），UI 只是它们的渲染层，业务逻辑不要写进组件。
3. `FileExplorer` 的路径与层级必须对齐，否则构造即断言——这是数据结构一致性检查。
4. 流式内容用 `StreamingText` / `StreamingMarkdown`，不要每帧重建整个消息列表。
5. AI 相关的"状态"（`AgentState`、`StepState`、`ChangeState`）都由调用方传入，组件不保存会话。
6. `messaging` 与 `chat` 都有"消息"概念但**不是同一个组件**：`messaging::ChatMessage` 面向 IM，`chat::MessageBubble` 面向 AI 对话，别混用。
